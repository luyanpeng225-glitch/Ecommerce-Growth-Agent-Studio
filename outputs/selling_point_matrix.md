## 7. 继承的待验证假设、风险字段和合规约束

继承自 Audience Insight Skill 的待验证假设：

- 户外运动爱好者可能优先被防抖、防水和固定方式证明打动。
- 旅行内容创作者会重视一人出行、多平台复用和轻量剪辑流程。
- 数码发烧友会通过样片、参数解释和真实评测建立购买信心。
- 认知到转化的主路径可以从内容平台种草过渡到天猫、京东等承接渠道。

继承自 Brief Parser Agent 的风险字段：

- `brand_name`
- `core_features[].proof`
- `specs.waterproof`
- `specs.stabilization`
- `core_features[4].feature`
- `positioning_statement`
- `availability.launch_date`

继续保留的合规约束：

- 不声称行业第一，除非有权威证明。
- 不使用最好、唯一、百分百稳定等绝对化表述。
- 不攻击具体竞品品牌。
- 不承诺任何场景下都不会损坏。
- 不暗示普通用户无需学习即可达到专业摄影师水平。
- 不暗示使用产品即可保证获得商业收益。
- 不把项目包装成单一品牌专属工具。
